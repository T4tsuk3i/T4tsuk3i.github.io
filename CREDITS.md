## Fictional world map

- **“Fantasy World Map”** by **Belohlavek** — https://opengameart.org/content/fantasy-world-map
  Released under **CC0 1.0 (public domain)** via OpenGameArt.org.
  A randomly generated fictional world, cropped and colour-muted to serve as the
  base layer beneath the knowledge graph. Attribution is shown on the panel even
  though CC0 does not require it.

  This is an original fantasy world, not a map from Log Horizon, Elder Tale,
  Destiny 2 or any other published setting. If a specific game map is ever used,
  it must be one released under a licence that permits reuse (with attribution),
  or one we hold rights to.

## Notes on originality

The layout, component names (`et-*`), colour tokens, typography pairing and the
dashboard composition in this repository are original work written for this site.
They are *informed by* common dashboard conventions (a sidebar index, a summary
ring, tag-driven topic cards) — not copied from any specific site, template or
theme. Where an external project inspired a pattern, it is credited above.

If you reuse this theme, keep this file with it.
